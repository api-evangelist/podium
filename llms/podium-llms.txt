# Podium

> Podium is a customer communication and lead-conversion platform for local businesses. Its v4 REST
> API covers text and webchat messaging, conversations, contacts, reviews and review responses,
> payments and invoicing, campaigns, appointments, phones/calls, products, feedback surveys and
> webhooks. All requests go to https://api.podium.com/v4/ over HTTPS with an OAuth 2.0 bearer
> token, are limited to about 300 requests per minute, and should carry a dated `podium-version`
> header.

This file was generated by API Evangelist from Podium's published surface; Podium does not serve
an llms.txt of its own (https://docs.podium.com/llms.txt returns 404).

## APIs

- [Podium API reference](https://docs.podium.com/reference/introduction): 86 operations across 12
  OpenAPI definitions, base URL https://api.podium.com/v4/
- [Authentication](https://docs.podium.com/reference/authentication): OAuth 2.0 bearer tokens
- [OAuth guide](https://docs.podium.com/docs/oauth): authorization code + refresh token; authorize
  https://api.podium.com/oauth/authorize, token https://api.podium.com/oauth/token; access tokens
  last 10 hours
- [OAuth scopes](https://docs.podium.com/docs/oauth-scopes): 17 published scopes; 25 in total once
  the scopes named inside the specs are included
- [Pagination](https://docs.podium.com/reference/pagination): cursor based, `limit` 1-100 (default
  10), `metadata.nextCursor`
- [Errors](https://docs.podium.com/docs/errors): custom `{code, message, moreInfo}` envelope
- [Versioning](https://docs.podium.com/docs/api-version): dated `podium-version` header
- [Webhooks](https://docs.podium.com/docs/webhooks): 26 event types, HMAC-SHA256 signed

## Notes

- Podium ships no MCP server, no A2A agent card, no llms.txt, no AsyncAPI and no /.well-known
  document of any kind.
- The only first-party client library is podium_ex (Elixir, hex.pm), last released 2020-02-13 and
  now archived.
- Idempotency exists on exactly one operation: `invoice.charge` accepts an optional
  `idempotencyUid`.
